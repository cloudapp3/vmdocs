# ロードマップ

vmflow v0.3.0 が現在の安定版です。L4 転送、ローカルコントロールプレーン、可観測性、ネイティブサービスのライフサイクル、トラフィック制御、TUI、組み込み API は現在利用できます。

## v0.3.0 より前に提供済みのベースライン

- [x] TCP、UDP、`tcp+udp` 転送
- [x] `ApplySnapshot`、ルールライフサイクル、YAML ホットリロード
- [x] ローカル CLI/TUI 管理
- [x] Prometheus メトリクスと構造化ログ
- [x] 管理認証とルールのプレチェック
- [x] 組み込み可能な Go ランタイム API

## v0.3.0 - 2026-08-03 リリース済み

- [x] ルール単位で共有する upload/download 帯域制限
- [x] 永続的な日次・月次トラフィッククォータ
- [x] チェックと送信転送向けの自動 DNS フェイルオーバー
- [x] インターフェースのカウンターとレートを表示する Host Network ダッシュボード
- [x] CLI/TUI の英語・簡体字中国語ローカライズ
- [x] ネイティブサービスのインストール、起動時実行、状態確認、TUI からの復旧
- [x] ローカル診断用の読み取り専用 stdio MCP ツール

## 今後の作業

- [ ] 既存接続のグレースフルドレイン
- [ ] イベントサブスクリプション API
- [ ] Windows と macOS での手動検証
- [ ] 公式 Docker イメージとデプロイ例
- [ ] クロスプラットフォームおよび統合テスト範囲の拡大

## 後のために予約

HTTP/HTTPS 転送と ACME/証明書管理はソース（`engine/https.go`、`engine/proxy.go`、`acme/`、`certstore/`、`certreview/`）に実装されていますが、現在のビルドでは無効です。NAT トラバーサル（`tunnel/`）も同様に保持されていますが結線されていません。どちらも L4 の表面が安定化したのちの将来のリリースの候補です。
