# Дорожная карта

vmflow v0.3.0 - текущий стабильный релиз. Перенаправление L4, локальная плоскость управления, наблюдаемость, жизненный цикл нативной службы, управление трафиком, TUI и API встраивания уже доступны.

## Базовые возможности, готовые до v0.3.0

- [x] Перенаправление TCP, UDP и `tcp+udp`
- [x] `ApplySnapshot`, жизненный цикл правил и горячая перезагрузка YAML
- [x] Локальное управление через CLI/TUI
- [x] Метрики Prometheus и структурированные журналы
- [x] Аутентификация управления и предпроверка правил
- [x] Встраиваемый API среды выполнения Go

## v0.3.0 - выпущена 2026-08-03

- [x] Общие для правила ограничения пропускной способности upload/download
- [x] Сохраняемые суточные и месячные квоты трафика
- [x] Автоматическое переключение DNS для проверок и исходящего перенаправления
- [x] Панель Host Network со счётчиками и скоростями интерфейсов в реальном времени
- [x] Локализация CLI/TUI на английский и упрощённый китайский
- [x] Установка нативной службы, запуск при загрузке, проверка состояния и восстановление через TUI
- [x] Инструменты MCP только для чтения через stdio для локальной диагностики

## Будущие работы

- [ ] API подписки на события

## Зарезервировано на будущее

Перенаправление HTTP/HTTPS и управление ACME/сертификатами реализованы в исходном коде (`engine/https.go`, `engine/proxy.go`, `acme/`, `certstore/`, `certreview/`), но отключены в текущей сборке. Обход NAT (`tunnel/`) также сохранён, но не подключён. Оба - кандидаты на будущий релиз, когда L4-поверхность стабилизируется.
